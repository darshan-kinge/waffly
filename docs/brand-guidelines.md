# Waffly

## Identity

**Waffly** is a lightweight, typed SDK for the WhatsApp Cloud API.

Tagline: **WhatsApp integrations, clearly typed.**

Short description: **Send messages, manage media, and verify webhooks with a straightforward TypeScript API.**

Use **Waffly** in prose, `waffly` for the package identifier, and `WhatsAppClient` for the existing exported client class. Spell the name consistently; avoid Waffly SDK variations in code identifiers. The package name is a local choice until registry availability and ownership are verified.

## Voice

Write for developers: direct, calm, and specific. Show working examples and state limits beside the relevant feature. Prefer “Meta accepted the message” over “Message delivered” until a delivery event confirms it. Describe tested behavior without promising universal compatibility, guaranteed delivery, or automatic retries.

Example introduction:

> Waffly connects your Node.js application to the WhatsApp Cloud API. Send typed messages, upload media, read templates, and verify incoming webhooks without runtime dependencies.

## Visual direction

Use a simple typographic wordmark, **Waffly**, with generous spacing and a restrained palette. A future symbol can combine a rounded chat outline with a small waffle grid; it should remain recognizable at package-icon sizes. This is a design direction, not an existing logo asset.

| Role | Color | Use |
| --- | --- | --- |
| Ink | `#172B24` | Main text and wordmark on light backgrounds |
| Cream | `#FFF8ED` | Primary background |
| Forest | `#176B45` | Links and primary accents on cream |
| Waffle | `#E7AD53` | Decorative highlights with ink text |

Use system sans-serif for prose and system monospace for code. Keep technical documentation readable without custom fonts or decorative imagery. Use ink text on cream or waffle; white text on forest is suitable for prominent labels. Verify contrast when introducing other combinations.

## Attribution and scope

Describe Waffly as an independent SDK for the Meta WhatsApp Cloud API. Do not imply official Meta sponsorship or use WhatsApp's logo as Waffly's own identity. Preserve existing copyright attribution.

This first branding pass covers naming, package metadata, documentation, voice, and a visual direction. Registry ownership, domains, trademark clearance, and finished logo artwork have not been established.
